SecGram для Windows (портативная версия)

1. Распакуйте папку SecGram в любое место (например, C:\SecGram).
2. Запустите SecGram.exe.

Все данные (вход в аккаунт, журналы SecGram) хранятся рядом с программой
в папке TelegramForcePortable и не смешиваются с официальным Telegram.
Для удаления просто удалите папку.

Настройки безопасности: меню (☰) -> «Безопасность SecGram».
